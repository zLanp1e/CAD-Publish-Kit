# CAD Publish Kit

[English](README.md)

**V0.1 测试版**：[安装说明](docs/INSTALL.md) · [版本说明](docs/RELEASE-NOTES.md) · [下载页面](https://github.com/zLanp1e/CAD-Publish-Kit/releases)

本地 Windows / SolidWorks 模型交付工具。当前支持多实体 STEP 拆分，以及装配体 STEP 的唯一零件导出；原生 SLDASM 输入流程尚未完成。

## 交付目录

```text
test-cases/MBNW02RZ-A-1-M1/
├── 原始文件.step
├── BOM.csv
└── parts/
    ├── body_001.step
    ├── body_002.step
    └── ...
```

原始 STEP、BOM 和零部件文件夹放在同一级。BOM 用 Excel 打开，包含实体名称、实体数量、对应文件、导出状态、前后面数和轴向偏差（毫米）。数量统计的是导出实体，不是恢复出的原始机械零件数量。原始文件名保留，内容不修改。

内部日志、扫描记录和历次验证报告保留在项目 `output/` 中，不放进交付目录。CAD 文件、BOM 和内部日志均不上传 GitHub。

## 桌面界面：日常使用

Windows 发布包完整解压后无需编译；源码下载需要先构建。双击根目录的 `Start CAD Publish Kit.cmd` 即可打开界面，也可以运行 `bin/CADPublishKit.Desktop.exe`。

1. 拖入一个 STEP / STP 文件，或者点击选择文件。程序自动连接或启动 SolidWorks 并开始分析，无需提前手动打开模型。
2. 在预览中查看配置、数量、实体数、面数及预计文件名，勾选要导出的项目。点击一行查看来源和原因，可“展开详情”。然后填写或选择保存位置。
3. 点击“导出交付包”，完成后可以打开输出文件夹。

默认保存到原文件旁的 `<源文件名>_delivery` 文件夹。也可以选原 STEP 所在目录，但已有 BOM.csv 或 parts 时拒绝覆盖。交付结构仍然只有原始 STEP、BOM.csv 和 parts/。

需要已安装并授权的 SolidWorks。使用同一 Windows 用户及权限级别，处理期间不要编辑 CAD 文档。程序分析独立副本，副本及报告保留在 `output/desktop-runs/`，不上传、不自动清理。项目目录需可写。模板自动查找失败时，点击“零件模板”选择空白 `.prtdot` 后重新分析。

界面目前为中文，支持导入为零件的可读 solid 实体；支持装配体 STEP 唯一零件导出，不支持 sheet 导出或原生 SLDASM 输入。发布包为便携 ZIP，无安装器；首次启动从本机 SolidWorks 自动复制接口库。

真实桌面测试完成 5 个实体的自动分析、导出和重新打开，界面保持响应。11 项核心检查、6 项桌面发布检查及 6 项脚本发布检查通过，发布检查使用合成数据。一次 SolidWorks 失去连接被记录为失败且未发布交付包，重启重试通过；更多输入和大量组件仍待验证。

## 批量检查文件夹

点击窗口顶部带文件夹图标的“批量检查文件夹”大导航区（选中时为绿色），输入路径或浏览选择目录，再点击“开始批量检查”。扫描所选目录（第 0 层）以及下方第 1–10 层子目录中的 `.step` / `.stp`，大小写均识别；同名文件按完整路径分别列出。

- **✓ 可拆分 · 已验证**：默认启用“实际导出并重新打开验证”，全部拆分目标通过当前导出检查。
- **✓ 可拆分 · 仅结构**：取消实际验证选项后，仅根据读取到的结构判断，不代表 STEP 导出已成功。
- **× 不可拆分**：只有一个 solid 或一个零件实例，当前模式不能拆成多个零件。单实体本身不代表文件损坏。
- **! 需检查 / 检查失败**：不支持的几何、读取或导出异常等，保留具体原因；不误判为不可拆分。
- **— 未检查**：尚未处理，或用户停止后未继续处理的文件。

可以筛选“只看 × / !”，选择一行打开原文件所在目录，或转到单文件预览。双击结果行可展开完整路径和原因。STEP 和对应 PDF 保持原位，不执行提取、移动或复制归档。

“本文件完成后停止”会在当前文件处理完毕后停止，不强制打断 SolidWorks 调用。处理期间不要手动编辑 CAD 文档。目录链接不跟随，超出 10 层或无法访问的目录会明确列出提示。扫描也会包含资料目录里已有的交付 STEP；工具自身内部工作目录会跳过，避免重复处理测试缓存。

分析会创建内部工作副本，实际验证会生成临时 STEP；均保留在工具 `output/desktop-runs/` 供排查，不写入资料目录或创建交付包。“查看本次记录”可打开自动保存的 JSON / CSV 结果；关闭窗口后可通过这些记录查阅历史。大量文件时耗时及临时磁盘占用会增加，未验证大规模资料库。

## 勾选导出说明

默认全选，支持全选、清空及逐项勾选。只导出部分项目时，原始 STEP 仍完整保留，BOM 的 Notes 明确包含 `SELECTED ITEMS ONLY; not a complete BOM`。未勾选的项目不会生成零件文件。分析后模型或选择映射发生变化时要求重新分析，不按旧清单盲目导出。

## 首次构建与命令行运行

在项目根目录运行：

```powershell
.\scripts\build.ps1
.\bin\CoreTests.exe
.\bin\DesktopPublishTests.exe
.\bin\BatchTests.exe
```

先在 SolidWorks 中打开对应模型并激活所需配置，再执行：

```powershell
# 扫描，内部清单写入 output/<case-name>/
.\scripts\run-case.ps1 -CaseName 'MBNW02RZ-A-1-M1'
# 导出并生成交付目录
.\scripts\run-case.ps1 -CaseName 'MBNW02RZ-A-1-M1' -ExportBodies -Template 'C:\ProgramData\SOLIDWORKS\SOLIDWORKS 2026\templates\gb_part.prtdot'
```

模板路径按本机修改，默认模板有效时可以不传 Template。案例名称只决定输出位置，不会自动打开或核对源模型。运行时不要编辑或切换文档，SolidWorks 与程序应使用同一 Windows 用户及权限级别。

已有 BOM.csv 或 parts 时，脚本会在导出前停止，避免覆盖。需要重跑时先自行保留或移动上一份交付结果。存在失败或恢复异常时不自动发布新交付包，详见 output 下的报告。

## 实际验证及限制

- Windows 11 x64、SolidWorks 2026 SP0.0、.NET Framework 4.8 或更高版本；其他版本未验证。
- 11 项核心测试通过。用户的 5 个实体均导出并重新打开成功，面数一致，六个轴向极值差值为 0，错误码均为 0。
- 原始 STEP 校验值未变；源文档的配置、选择对象/标记、路径、保存标志及活动状态检查一致。
- 采用实体复制到独立临时零件文档的方式导出，不保存源文档。只关闭本次创建的临时文档，失败输出保留供诊断。
- 当前只导出 solid 实体，包含隐藏实体；sheet 暂不导出。STEP 使用现有设置，本机实测 AP203。
- 位置范围检查容差为 1e-6 米，不等于完整几何等价证明或第三方 CAD 验收。
- 装配体去重按文件路径和配置；抑制、未加载子装配体可能导致后代不可读。原生装配树数量验收仍待完成。
- CSV 为 UTF-8 BOM，包含必要转义及公式前缀保护；实例 ID 和实体 ID 只在单次运行内有效。
- 退出码 0 为当前检查通过，1 为前置/致命错误，2 为需要检查。扫描范围限制仍适用于退出码 0。

完整命令和边界见英文 README。桌面 UI 已实现拖入分析、路径选择和导出；三维展示及爆炸图未实现。项目代码使用 MIT 许可证；发布包不含第三方 DLL，详见 THIRD-PARTY-NOTICES.md。

装配体 STEP 现在支持预览及导出：按导入组件路径＋引用配置分组，重复实例合并计数，每类零件的多个 solid 保存在同一 STEP 中。引用配置可在状态列提示及 BOM 中查看。

## 装配体 STEP 实测

CZ-80 实测识别 12 类零件、19 个零件实例、4 个装配节点。12 份零件 STEP 全部重新打开通过；两个零件分别含 2 和 3 个 solid，均保持在各自单一零件文件中。前后 solid 数、面数一致，整体六轴极值偏差均为 0；组件位置、配置及保存状态未改变。原先 5 实体模型的真实回归导出也通过。

完整装配体使用原始 STEP 的逐字节副本，保留原结构及位置，不另行生成总成文件。零件 STEP 使用零件自身坐标；内部报告保存实例层级与 SolidWorks 原始变换数组。BOM 的 ComponentSourcePath 为导入时的组件标识路径，可能不是磁盘上的独立源文件。SolidWorks 导入时产生的名称可能有下划线或变化后缀，不猜测原始名称。

抑制、未加载、虚拟件、曲面和装配级修改实体等暂不支持，出现时明确阻止完整交付。不同配置和第三方查看器仍待更多真实验证，范围及面数检查不等于完整几何等价证明。11 项核心检查、6 项桌面发布/命名检查、6 项脚本发布检查通过；后两类为合成测试。
